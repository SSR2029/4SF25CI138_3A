# Swiggy Restaurant Data Analysis

## Objective
To analyze Swiggy restaurant data using Python and Pandas, clean the dataset, handle missing values using mean imputation wherever applicable, generate insights, and visualize the results.

## Dataset
The project uses `swiggy_file.csv`, containing Swiggy restaurant information.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
1. Loaded the CSV dataset using Pandas.
2. Examined the dataset shape, columns, data types, missing values, duplicates, and statistical summary.
3. Removed duplicate rows.
4. Standardized column names.
5. Converted relevant columns to numeric data types.
6. Handled missing numeric values using mean imputation.
7. Handled missing categorical values using mode imputation.
8. Generated insights about locations, cuisines, ratings, prices, and offers.
9. Created visualizations using Matplotlib and Seaborn.
10. Saved the cleaned dataset as `swiggy_dataset_cleaned.csv`.

## Output Files
- `swiggy_analysis.py` — Python source code
- `swiggy_file.csv` — original dataset
- `swiggy_dataset_cleaned.csv` — cleaned dataset
- PNG files — data visualizations

## Conclusion
This project demonstrates data loading, data cleaning, missing-value handling, insight generation, and visualization using Python.
